# VK Sender Telegram Bot (aiogram 3.x)

Telegram-бот на базе современной асинхронной библиотеки **aiogram 3.x**, выступающий удобным интерфейсом для организации рассылки сообщений по страницам и чатам ВКонтакте.

---

## 🚀 Возможности

1. **Загрузка базы ссылок:**
   - Прием текстового файла `.txt` со ссылками на страницы, пользователей, группы или диалоги ВКонтакте (каждая ссылка с новой строки).
   - Поддержка отправки ссылок напрямую в чат обычным текстом.
   - Автоматическая очистка, валидация формата ссылок и фильтрация дубликатов с выводом статистики (всего строк, уникальных ссылок, удаленных дублей).

2. **Задание текста рассылки:**
   - Ввод текста через Telegram.
   - Предварительный просмотр перед запуском (количество адресатов, ориентировочное время, статус токена, предпросмотр сообщения).

3. **Интерактивный процесс рассылки:**
   - Отображение динамического прогресс-бара прямо в сообщении (`[████░░░░░░] 4/10`).
   - Подсчет успешных отправок и ошибок в реальном времени.
   - Защита от спам-фильтров: настраиваемая задержка между отправками (по умолчанию 2 секунды).
   - Возможность экстренной остановки рассылки кнопкой «⏹ Остановить».
   - Детальный отчет по завершении рассылки.

4. **Интеграция с VK API:**
   - Модульный сервис `bot/services/vk_service.py`.
   - **Режим симуляции (по умолчанию):** если токен VK еще не введен, бот позволяет протестировать весь сценарий без ошибок, имитируя отправку сообщений.
   - **Реальная отправка:** поддерживает токены пользователей или сообществ, резолвит `screen_name` (например, `vk.com/durov` или `vk.com/club123`) в числовые `peer_id` и отправляет сообщения через метод `messages.send` API v5.199.
   - Возможность установить токен VK прямо из меню бота в Telegram (`⚙️ Настройки VK API`) или через файл `.env`.

## 📁 Структура проекта

```text
vk_sender_bot/
├── .env                              # Конфигурация (BOT_TOKEN, VK_TOKEN, DELAY)
├── requirements.txt                  # Зависимости
├── main.py                           # Точка входа и запуск polling
├── README.md                         # Документация
└── bot/
    ├── config.py                     # Загрузка и динамическое обновление настроек
    ├── states/
    │   └── broadcast.py              # FSM состояния (BroadcastStates, SettingsStates)
    ├── keyboards/
    │   └── inline.py                 # Инлайн-клавиатуры меню, настроек и рассылки
    ├── services/
    │   ├── parser.py                 # Парсинг и валидация ссылок ВКонтакте
    │   └── vk_service.py             # Интеграция с API ВКонтакте и симуляция
    └── handlers/
        ├── __init__.py               # Регистрация роутеров
        ├── start.py                  # Главное меню (/start, /help, /cancel)
        ├── settings.py               # Настройки токена VK и задержки
        └── broadcast.py              # Обработка файлов, текстов и процесс рассылки
```

## 🔧 Управление сервисом

Бот работает как системная служба пользователя `systemd`:

- **Проверить статус:**
  ```bash
  systemctl --user status vk_sender_bot
  ```
- **Посмотреть логи:**
  ```bash
  journalctl --user -u vk_sender_bot -f
  ```
- **Перезапустить:**
  ```bash
  systemctl --user restart vk_sender_bot
  ```
- **Остановить:**
  ```bash
  systemctl --user stop vk_sender_bot
  ```
